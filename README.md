此 **Thingiverse 3D 模型数据集样本**包含 **2,923 条记录**，并使用 **Bright Data API** 提取。

## 数据点

| 字段名称 | 描述 |
|------------|-------------|
| `url` | Thingiverse 上特定 3D 模型的直接 URL。 |
| `id` | 数据集中每个 3D 模型条目的唯一标识符。 |
| `domain` | 3D 模型数据来源的域名。 |
| `title` | 创作者为 3D 模型指定的标题或名称。 |
| `description` | 3D 模型的详细描述，通常包括其用途或创作灵感。 |
| `license` | 发布该 3D 模型所采用的知识共享许可类型。 |
| `images` | 指向 3D 模型图片的 URL 列表。 |
| `creator_details` | 3D 模型创作者的信息，可能包括姓名和个人资料。 |
| `tags` | 与 3D 模型相关的分类关键词或标签。 |
| `date_posted` | 3D 模型在平台上的发布日期。 |
| `download_url` | 可下载 3D 模型文件的 URL。 |
| `num_comments` | 其他用户对该 3D 模型的评论数量。 |
| `num_likes` | 该 3D 模型获得的点赞或赞成票数量。 |
| `num_files` | 3D 模型包中包含的文件总数。 |
| `print_settings` | 建议用于 3D 打印该模型的具体设置，例如材料和打印速度。 |


## 应用场景

### 1. 3D 打印研究
分析热门 3D 模型及其属性，以了解 3D 打印设计趋势和创作者偏好。

### 2. 设计教育
将知识共享 3D 模型的数据用于设计课程教学，通过真实案例提升学习效果。

### 3. 知识共享许可分析
研究 3D 模型所用许可的分布和类型，以了解创作者的许可偏好及其影响。
